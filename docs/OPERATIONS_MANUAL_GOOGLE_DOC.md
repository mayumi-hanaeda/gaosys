# タダスク講師を始めてみたい人の申込みフォーム 運用マニュアル

更新日: 2026-07-04
対象バージョン: 本番 Web アプリ @96

## 1. はじめに

この文書は、「タダスク講師を始めてみたい人の申込みフォーム」の運用担当者向けマニュアルです。

フォームから申込みが送信されると、管理スプレッドシートへの記録、Calendar 予定の作成または更新、評価シートの作成、Google Chat 通知、自動返信メール送信が行われます。

このマニュアルでは、運用担当者が日常的に確認・変更する場所と、開発者へ依頼すべき変更の切り分けを説明します。

## 2. このフォームで自動化されていること

申込者がフォームを送信すると、システムは主に以下を行います。

| 処理 | 内容 |
| --- | --- |
| 申込記録 | 管理スプレッドシートの申込リストへ申込内容を記録します |
| Calendar 登録 | 設定用シートの内容をもとに Calendar 予定を作成または更新します |
| 評価シート作成 | 設定されたテンプレートをコピーして、申込者ごとの評価シートを作成します |
| 編集権限付与 | 作成した評価シートに申込者の編集権限を付与します |
| index 登録 | 管理用 index シートへ評価シート情報を登録します |
| Chat 通知 | 運営向け Google Chat に申込内容と評価シート情報を通知します |
| 自動返信メール | 申込者へメールを送信します |

## 3. 管理スプレッドシートの構成

運用で主に見るシートは以下です。

| シート | 用途 |
| --- | --- |
| 名前リスト | フォームで名前候補として使われる講師情報 |
| 申込リスト | フォーム送信後の申込内容と処理状況 |
| 設定用 | Calendar、評価シート、自動返信メールに関する設定 |
| index | 評価シートと講師管理情報を紐づける管理表 |

通常の運用で設定変更する場合は、まず `設定用` シートを確認します。

## 4. 設定用シートの使い方

システムは `設定用` シートの `A2:G2` を読み込みます。

`A1:G1` は見出しです。コードは見出し行を処理に使いませんが、運用上の意味が分かるように残してください。

| セル | 設定名 | 必須 | 入力する値 | 備考 |
| --- | --- | --- | --- | --- |
| A2 | Calendar タイトル | 必須 | Calendar 予定のタイトル | 空欄不可 |
| B2 | Calendar ID | 必須 | 予定を作成する Calendar の ID | 既存予定の更新にも関係します |
| C2 | MTG 時間 | 必須 | 分単位の数値 | 例: `30`, `60` |
| D2 | 開始時刻 | 任意 | `HH:mm` 形式の時刻 | 空欄の場合は `20:00` |
| E2 | 評価シートテンプレート ID | 必須 | コピー元スプレッドシートのファイル ID | フル URL は不可 |
| F2 | 自動返信メール件名 | 必須 | 申込者へ送るメール件名 | 置換タグを使用可 |
| G2 | 自動返信メール本文 | 必須 | 申込者へ送るメール本文 | 置換タグを使用可 |

### A2: Calendar タイトル

フォーム送信後に作成または更新される Calendar 予定のタイトルです。

例:

```text
タダスク講師 はじめて説明
```

### B2: Calendar ID

予定を作成する Calendar の ID です。

この値を別の Calendar に変更すると、既存予定の更新に失敗することがあります。変更する場合は、本番 Web アプリの実行アカウントが対象 Calendar に書き込みできることを確認してください。

### C2: MTG 時間

Calendar 予定の長さを分単位で入力します。

例:

```text
30
```

### D2: 開始時刻

フォームで選ばれた日付と組み合わせて、Calendar 予定の開始日時を作ります。

入力形式:

```text
20:00
```

空欄の場合は、自動的に `20:00` として扱われます。

`D1` は見出しセルです。システム処理では使われません。

## 5. 評価シートテンプレートを変更する方法

評価シートテンプレートを変更する場合は、`設定用!E2` を変更します。

`E2` には Google スプレッドシートのフル URL ではなく、ファイル ID だけを入力してください。

正しい入力例:

```text
1abcDEFghiJKLMnopQRSTUVWXYZ1234567890
```

フル URL の場合:

```text
https://docs.google.com/spreadsheets/d/1abcDEFghiJKLMnopQRSTUVWXYZ1234567890/edit
```

入力するのは `/d/` と `/edit` の間にある ID 部分だけです。

```text
1abcDEFghiJKLMnopQRSTUVWXYZ1234567890
```

フル URL を入れると、評価シート作成が失敗する可能性があります。

評価シートの保存先フォルダは `設定用` シートではなく、Apps Script の Script Properties にある `EVALUATION_SHEET_FOLDER_ID` で管理されています。

## 6. 自動返信メールを変更する方法

自動返信メールは `設定用!F2:G2` で変更できます。

| セル | 内容 |
| --- | --- |
| F2 | 自動返信メールの件名 |
| G2 | 自動返信メールの本文 |

以下のタグを入れると、送信時に申込内容へ置き換わります。

| タグ | 内容 |
| --- | --- |
| `{{name}}` | 申込者の名前 |
| `{{tadasukeName}}` | タダスクネーム |
| `{{startDate}}` | 希望開始日 |
| `{{challenge}}` | チャレンジ講師希望の有無 |
| `{{freeText}}` | 自由記述 |
| `{{evaluationSheetUrl}}` | 作成された評価シート URL |
| `{{responseSummary}}` | 申込内容のまとめ |

上記以外のタグを入れると、メール送信が失敗する可能性があります。

## 7. 申込後に確認する場所

申込後は、必要に応じて以下を確認します。

| 確認場所 | 確認内容 |
| --- | --- |
| 申込リスト | 申込内容、Calendar ID、開始日時、処理状況 |
| index | 評価シートへのリンクが登録されているか |
| 評価シート保存先フォルダ | 申込者ごとの評価シートが作成されているか |
| Google Chat | 申込通知と評価シート URL が届いているか |
| Calendar | 予定が作成または更新されているか |

## 8. トラブル時の確認手順

### 評価シートが作成されない

以下を確認してください。

1. `設定用!E2` にテンプレートのファイル ID が入っているか
2. `E2` がフル URL になっていないか
3. テンプレートファイルを本番 Web アプリの実行アカウントが閲覧できるか
4. 評価シート保存先フォルダに本番 Web アプリの実行アカウントが作成権限を持っているか

### 自動返信メールが送信されない

以下を確認してください。

1. `設定用!F2` が空欄ではないか
2. `設定用!G2` が空欄ではないか
3. 使用している置換タグが、このマニュアルに記載されたタグだけか
4. 評価シート作成や権限付与が失敗していないか

### Calendar 登録に失敗する

以下を確認してください。

1. `設定用!B2` の Calendar ID が正しいか
2. 本番 Web アプリの実行アカウントが対象 Calendar に書き込みできるか
3. 既存予定を更新する場合、元の予定が同じ Calendar に存在しているか

### Chat 通知に評価シート URL が出ない

以下を確認してください。

1. 評価シート作成が成功しているか
2. `設定用!E2` のテンプレート ID が正しいか
3. 評価シート保存先フォルダの権限が正しいか

## 9. 変更依頼と GitHub 対応の切り分け

### スプレッドシートだけで対応できる変更

以下は `設定用` シートを変更すれば対応できます。

| 変更内容 | 変更場所 |
| --- | --- |
| Calendar 予定タイトル | `設定用!A2` |
| Calendar ID | `設定用!B2` |
| MTG 時間 | `設定用!C2` |
| 開始時刻 | `設定用!D2` |
| 評価シートテンプレート | `設定用!E2` |
| 自動返信メール件名 | `設定用!F2` |
| 自動返信メール本文 | `設定用!G2` |

### GitHub 対応が必要な変更

以下はコード変更が必要です。開発者へ依頼してください。

- フォーム項目の追加・削除
- 入力チェックの変更
- 評価シート作成ロジックの変更
- Chat 通知本文の構造変更
- メールで使える置換タグの追加
- Calendar 登録ロジックの変更
- Script Properties のキー追加
- 本番デプロイが必要な変更

## 10. 開発者へ連絡するときに伝える情報

不具合や変更依頼を開発者へ連絡するときは、以下を分かる範囲で伝えてください。

| 項目 | 例 |
| --- | --- |
| 発生日時 | 2026-07-04 10:30 頃 |
| 申込者名またはタダスクネーム | 例: 山田太郎 / たろう |
| 何が起きたか | 評価シートが作成されない、メールが届かないなど |
| 期待していた結果 | 評価シート URL が Chat に出るはずだった |
| 確認した場所 | 申込リスト、index、Chat、Calendar など |
| エラー表示 | Chat 通知や処理状況に表示された文言 |
| 直前に変更した設定 | `設定用!E2` を変更した、メール本文を変更したなど |

機密情報、Webhook URL、個人情報を必要以上に共有しないでください。
